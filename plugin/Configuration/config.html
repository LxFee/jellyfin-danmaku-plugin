Jellyfin 弹幕

适配 Jellyfin 12.2 的网页内置播放器。播放时使用弹幕按钮开关，旁边的弹幕设置按钮可调整样式与手动匹配。

个人开关、样式和匹配记录保存在当前浏览器。本地 XML 模式需另装提供 /api/danmu/{itemId}/raw 的数据插件；本插件默认从在线弹幕源加载。

两种方式择一使用，切换后保留另一种方式已保存的配置。
默认使用弹弹play API；自建接口需允许浏览器跨域访问。
默认使用上游公共 CORS 代理；留空时直接访问 API。地址不能包含账号或 token。

由 Jellyfin 主站签名并直接请求弹弹play，所有用户共用此应用额度。此模式不使用公共代理或浏览器自定义接口。

在弹弹play开发者中心申请应用凭据。密钥保存在主站的插件配置中，仅管理员可查看或修改。
